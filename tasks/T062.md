# T062 U1/U5 加线候选状态与同日岩馆短名

## 背景与问题

按 2026-11-20 复审交接执行。以上一通过自测的任务作为集成前置，验收绑定本批最终提交。

## 开发范围（允许修改）

复用 routeCompletion 在本馆候选标出未完攀、已完攀和待确认。已完攀抱石可直接进原线路历史而不新增场次或线路关联。保留顶绳、先锋重复记录。仅在同日多馆的本日按钮给出可辨岩馆短名。

## 禁止变更

保留现有页面结构、试用资料、已验收归属、普通清缓存保护及未涉及的行为。禁止改动 AppID、实际 CloudBase 配置与权限，禁止在生产档案或真实云端注入故障。合并和发布由负责人另行授权。

## 验收标准

- [ ] 跨日已完攀抱石从本馆候选点历史，档案和选择不变；待确认提示稳定；未完攀及顶绳、先锋照常关联。
- [ ] 同日两馆按钮都有岩馆短名，现有场次 ID、编号、短按和长按不变。

## 建议验证命令

```powershell
node --test tests/*.test.cjs
git diff --check
```

## 测试与人工验证边界

先用合成档案、严格微信参数对象及可恢复故障验证。按分批验收单在同一冻结提交复核适用的原生页面、正式构建和手机待验。

## 回滚办法

回退本批隔离分支中的任务提交并复验既有记录读取。验收资料与当前试用工程保留。
