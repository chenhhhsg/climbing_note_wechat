# T023 从逐把明细或跨日历史选片预览

[整项验收](../docs/product/逐把视频本机回看-v0.1-整项验收.md)

## 背景与问题

T036–T037 已把逐把明细和长期线路资料分开。本单把两处实际把次行接入同一个视频页。

## 开发范围（允许修改）

先读 `pages/training-attempts/`、`pages/training-route/`、`utils/training-record-actions.js` 的归属校验、`utils/training-store.js` 的有效把次读取及 `devtools/media-check/pages/media-check/media-check.js`。新增正式页四件套。列表只显示关联状态与文字入口，传档案、场次、线路、原把次四个 ID。跨日历史使用分组的原场次，进入、返回刷新和异步操作前核对最新本机档案。以单个选项对象调用 `wx.chooseMedia`，限定相册单选视频。临时路径只进入待确认预览，持久写入由 T026 实现。现有正式包测试仅更新新增路由及文件清单。

## 禁止变更

训练档案结构、记把、撤回恢复、线路照片、清单、自测、旧云读取和 tabBar 沿用原实现。旧汇总按原口径读取。

## 验收标准

- [ ] 同线 A/B 两把仅 B 得到选片预览。跨日打开 B 使用原场次。缺参、串档、同名异线、已撤回、待保存或旧汇总均无法新挂片。
- [ ] 相册取消和预览取消均可立即重选。选择失败给出可见提示，迟到回调、连点和离页不影响其他把次。本单预览不创建持久文件或索引。
- [ ] 正式包包含新页四件套，原路由、tabBar、试用工程排除和缺文件断言继续通过。

## 建议验证命令

~~~powershell
node --test tests/attempt-video.test.cjs tests/training-history.test.cjs
node --test tests/*.test.cjs
git diff --check
~~~

## 测试与人工验证边界

离线用按微信单对象参数定义的模拟，核对归属、调用和回调行为。两处入口、真实相册和可见布局在整项 QA 复验。

## 回滚办法

候选内按依赖逆序回退本批代码并复跑原训练主流程。保留已有本机视频副本、索引、相册原件和训练档案。
