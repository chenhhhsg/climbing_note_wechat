# T035 首页单行入口与独立下次想爬清单

## 背景与问题

首页和本场都展开了多条想爬线路，挤占记录入口。T034 已保留小结加入清单；这一步把浏览入口收束到首页。 [整项验收](../docs/product/训练页信息层级重整-v0.2-整项验收.md)

## 开发范围（允许修改）

先读 `pages/index/index.js` 的 `refreshWishlist`、`utils/training-wishlist.js`、`training-session` 和 `training-route` 的清单操作。新建并注册 `pages/training-wishlist/training-wishlist` 四件套，首页一行显示标题及数量；独立清单保留原按馆分组、状态、回看与继续原线的能力。移走场内和首页内联清单，原线资料仍可加入、移除或归档。首页其他功能原位可达。

## 禁止变更

不重建清单、创建并行收藏表或迁移照片。损坏的条目不覆盖，其他档案不同名或同名线路都不可误读。包测试仅添本单路由，旧页面测试只调整搬迁的清单交互。

## 验收标准

- [ ] 0 条时首页仍有可点的单行入口；构造同档两馆同名线、已完成及已归档线，首页数量 = `listWishlist(archive).items.length`。独立清单的分组、状态文字与已有数据一致。
- [ ] 从独立清单点选第二馆 B，资料显示 B 的原照片/备注/历史；返回清单再回首页，活动场次不变。资料页移除或小结勾选后再回首页，数量据实刷新。
- [ ] 旧档无清单键、损坏键、跨档碰撞各有离线夹具。只读打开不写盘，损坏时显示失败与重试；原始值和照片索引保持。现有继续该线的显式操作可到达，单纯导航不会创建关联。
- [ ] 首页和本场不再铺全清单。保留原有小结勾选、记录 tab、首页开始／继续及其他 tabBar 路由。

## 测试与人工验证边界

Node 从首页入口、清单、资料及返回刷新对账；模拟器核验单行在小屏可点、系统返回层级，手机与整项候选统一走查。

## 回滚办法

按依赖回退本单新增路由、资料／首页交接和场内清单展示，复用同一清单键复核原条目、状态、照片和已选场次。
