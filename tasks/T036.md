# T036 单线记把、逐把备注与长期线路资料

## 背景与问题

前三层数据已有稳定的档案、场次和长期线路 ID。用户需要在一条线上连续记把，照片和跨天记录放到资料页，逐把详情用原把次编辑备注。 [整项验收](../docs/product/训练页信息层级重整-v0.2-整项验收.md)

## 开发范围（允许修改）

注册 `pages/training-record/training-record` 和 `pages/training-attempts/training-attempts` 两套原生四件套。从现有场内线路入口打开单线页，加线成功直达。将训练页已有写入、待提交、撤回／恢复和按把纠错的页面逻辑移入适当位置；如需提取既有事件处理，共用的页面逻辑限 `utils/training-record-actions.js`。先读 `utils/training-store.js`、`training-rules.js`、训练页及 `training-route` 的原生照片、卡点和历史实现。线路资料承接照片/卡点、跨天历史和原有操作。

## 禁止变更

不改存储层、schema、去重算法、图片管理或分级规则。不可用页面下标、日期或 activeRouteId 替代原 ID，不给被撤回的把次重排序。旧测试只搬运已迁移的页面绑定/断言；保留照片生命周期、回执、损坏和原 ID 负例。

## 验收标准

- [ ] 单线页按 archiveId＋sessionId＋routeId 验证归属。两场、两线同名同级，A 记到第 3 把后经明细写入指定 attemptId；保存、取消、失败重试、返回与重开均只影响这把。明细仅列本场该线；从资料查看跨天历史可辨同日不同场，按原 ID 回到对应记录。
- [ ] 从单线页撤回、返回列表、重开 A，再恢复，3→2→3，原 ID、序号、结果与备注一致。测试写前失败、写成后回执丢失、晚到的保存/相反操作及另一档同 ID。单线页显示可见的保存状态和属于原操作的重试。
- [ ] 昨日已完攀抱石回看锁定，本场有效完攀、待确认与唯一完攀撤回/恢复沿用既有规则。纠错「改为未完成」保留一把。顶绳、先锋均可重复记录完攀。
- [ ] 单线页以结果和最近一把为主，提供明细与资料入口。资料页空照片、已有照片/卡点、重选取消、原图更换/移除与跨天历史均可达，返回仍在原线。旧记录 tab 与独立清单进入资料的路由仍兼容；资料的「当天再记」可进正确的单线页。
- [ ] 对新增路由适配 G09、V05、PK03；保留包外试用目录隔离、原路由与图标。用真实 WXML 数据集触发迟到点击，禁止第二次点击原位置落到相反动作或另一把。

## 测试与人工验证边界

离线测试覆盖页面绑定及合成数据持久对账。真实文件选择器、取消重选、卡点编辑、连续两次同坐标命中及软键盘返回在同一原生候选取证。手机照片与实际重开归入负责人试用。

## 回滚办法

先撤回本单导航转换，再撤回新增页和页面事件提取；保留原存储和持久回执，用含撤回、待保存项和旧照片的夹具重开验证。
