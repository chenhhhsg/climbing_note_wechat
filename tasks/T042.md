# T042 本场逐把与原把次纠错

[整体验收](../docs/product/现场记录与历史回顾-v0.1-整项验收.md)

## 背景与问题

单线记录把更正放在独立「点错了完攀？」区，离目标把次较远。逐把明细的名字也未说明范围。

## 开发范围（允许修改）

将标题、入口和视频页相关提示中的可见称呼统一为「本场逐把」。保留按原档案、场次和线路定位的逐把页。移除单线页的独立更正区，在符合既有更正条件的最近一把旁展示「更正结果」，较早的合资格把次在本场逐把对应行处理，跨场候选继续从线路历史的原把次处理。确认中能辨认原把次和预期结果。复用现有更正和撤回恢复动作及其重试参数。保留最近一把撤回与恢复的原位操作。

## 禁止变更

保留现有资格边界、次数统计、把次 ID 与序号、视频副本和备注保存逻辑。本场逐把只展示原场原线。旧汇总、绳攀、已撤回及待保存把次保持既有操作资格。共用动作层仅为接入口和刷新适配，持久化、重试规则与现有线路历史更正能力保持。

## 验收标准

- [ ] 本场逐把只显示原场次及原线路，仍能按原把次读写备注、进入视频。线路历史继续按原场显示跨天把次。单线记录的独立更正区消失。
- [ ] 两把夹具上更正符合现有资格的完攀，原把 ID、序号、备注、视频标识及本机副本一致，有效把数仍为 2、完攀数减一。可从最近一把旁操作，较早候选能从本场逐把定位。
- [ ] 撤回最新一把后有效把数减一，原位显示恢复，恢复后回到原计数。旧按钮、取消、连点、跨线或跨场、失败重试和重开均指向原把，历史统计与单线锁定状态按既有规则联动。

## 测试与人工验证边界

离线比较有效把数、完攀、原身份和视频关联，注入失败及迟到事件。手机在两把测试场次实际更正、撤回、恢复及从原把播放。视频维持本机存储。

## 回滚办法

按集成依赖逆序回退入口和动作适配，复查场次计数、备注及视频回看。已写入的训练记录按现有规则读取。
