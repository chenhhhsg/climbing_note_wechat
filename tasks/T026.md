# T026 保存本机持久副本并保护在用视频

[整项验收](../docs/product/逐把视频本机回看-v0.1-整项验收.md)

## 背景与问题

用户确认保存后，原把次要在冷启动和断网时读到同一段视频。临时路径可能在退出后失效。

## 开发范围（允许修改）

先读 T023/T024、`utils/training-photo-files.js`、`utils/training-photo-space.js`、`utils/training-store.js` 和 `pages/profile/profile.js` 的清缓存。用独立视频索引及 `wx.env.USER_DATA_PATH` 下的档案专属视频目录，关联档案、场次、线路、原把次和片段 ID/版本，保存相对文件标识与实际字节。按单片、视频总量和替换期间新旧副本并存的峰值核对空间，为共用空间的照片留余量。显示占用和可执行的超限提示，正式阈值以手机样片的大小、质量和耗时定。

明确确认后先写新副本并核对可读、实际大小有效，再按当前归属和版本提交索引，最后清理已无引用的旧副本。移除核对当前片段版本，先解除关联再回收副本。提交没有明确回执时先读回再判断，允许安全重试和重启恢复。普通清缓存沿用既有照片与训练缓存策略并补充视频保护提示。清理仅限能确认由本功能创建、无引用且无在途写入的文件。

## 禁止变更

保留训练档案、自测、线路照片和卡点、其他档案和系统相册原件。云端、上传、AI、手工时间点和数据迁移留在后续范围。

## 验收标准

- [ ] 确认保存后使临时路径失效，再重建页面与文件服务，场内和跨日均读到 B 的持久文件、实际字节和原片段。A 不挂片。缺文件时 B 仍可看记录并重选。
- [ ] 取消替换保留旧片。确认替换须在新关联提交后回收无引用旧副本。移除只处理小程序内的副本，原把、备注和相册原片仍在。撤回、恢复同一把后仍读到原片。
- [ ] 覆盖重复确认、跨页或换档迟到、真实文件写入失败、索引写入失败、提交后丢回执、容量预检和真实配额失败、清理失败及冷启动恢复。旧视频可用、训练继续且无错绑或重复副本。
- [ ] 普通清缓存后，已关联视频（含撤回后待恢复）和线路照片仍可回看。训练、卡点、自测及未知文件保持原值。

候选内按依赖逆序回退本批代码并复跑原训练主流程。保留已有本机视频副本、索引、相册原件和训练档案。
