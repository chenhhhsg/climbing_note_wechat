# T004 验证测试账号能打开自己的旧记录，且不能读取另一账号的私有记录

## 背景与问题

M0 的旧记录列表已有离线回归，但首批模拟器使用过注入数据。进入 M1 前需要知道当前小程序在独立测试云环境中能否真正读到属于自己的记录。先读 `app.js`、`project.config.json`、`utils/db.js` 中的 `getRecords` 和 `getRecordById`、列表与详情页及第一批执行报告。入口使用占位值 `your-env-id`；本地 `cloudbase/` 子目录名仅作查找线索。

## 开发范围（允许修改）

仅新增上述核验报告。先核对当前 AppID 与负责人指定的独立测试环境的关联、可用测试身份、集合及既有虚构样例。现场操作使用小程序客户端身份；可用开发者工具的本地测试会话显式指定已确认环境。分别记录实际查询和页面真走查；如只完成查询，注明页面待验。报告使用 A、B 和样例别名，记录操作者、时间、步骤、观察结果、判定和可复测的证据位置。

## 禁止变更

不得猜测环境或使用默认环境试读。不得改项目配置、AppID、云规则、集合、云函数、记录列表或其他业务代码；不得登录生产环境、读取个人记录、创建测试数据、上传或部署。报告中不要保存凭据、OpenID、原始记录或个人字段。此次不派发 M1 两页开发。

## 验收标准

- [ ] **环境与样例**：能核对该环境明确用于测试且关联当前 AppID；A、B 为两个独立测试身份，各有至少一条事先确认归属的虚构私有记录。缺少任一前提，注明缺项并停止相应云端核验。
- [ ] **本人可读**：A 经客户端按项目的列表查询读到 A 的样例，按同一 ID 读详情成功，能核对预先约定的样例字段；B 对自己的样例执行同一正向对照。记录每个实际入口和结果。
- [ ] **跨账号隔离**：用 B 检查 A 的已知私有样例，既核对列表结果（覆盖样例所在数据范围），又直接按 A 的 ID 读详情。两条路径均未返回 A 的记录，且同一会话可正常读取 B 自己的样例。若泄露，只记录脱敏复现条件，停止扩大查询。网络错误、空库、分页未覆盖或管理员查询不能充当隔离证据。
- [ ] **离线与范围**：复跑基线 27 项 Node 测试，记录退出码与各项计数；相对执行起点的候选差异连同未跟踪文件仅包含这份报告。列出尚待验证的读写、分页、设备场景及各自所需条件。

## 测试与人工验证边界

离线可核对代码、交付范围并复跑回归。实际的本人读取和跨账号隔离都要有指定测试环境与客户端身份的证据。若当前配置不能走通页面，报告区分客户端查询和页面结果。若缺少环境、样例、身份或权限，QA 对相应必验项给出 `BLOCKED`，写明负责人需要补什么；若在前提满足时读错或越权，给出 `CHANGES_REQUESTED` 及复现路径。写入与弱网重试、视频真机验收另行安排。

## 回滚办法

本任务对云端只读。执行结束退出测试会话、清除临时的环境绑定；若报告有误，保留原始观察记录并修订报告。若需整体撤销，撤销该报告的独立提交即可。
