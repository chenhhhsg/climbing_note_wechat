# T028 在线路主照片上标记手法与脚法

## 背景与问题

用户想在岩点的位置留一句「左脚踩这里」，下次打开原照片可以直接找到。 [本批需求及整体验收](../docs/product/岩馆手册-线路清单卡点与场次小结.md)

## 开发范围（允许修改）

从原线路详情的大图进入标记模式，支持点选、填文字、移动、编辑和删除。使用当前档案、线路和主照片 ID 标识标记，用相对原图的位置持久保存，换屏或更换缩略图时还原。

## 禁止变更

不把标记烧进照片，不上传原图或标记，不自行迁移旧照片或加入视频、多人共享。 保留创意总监的正式界面风格，开发与验证仅用合成数据和独立工作区。

## 验收标准

- [ ] 在同一张图左右分别加两条提示，保存、重开、换大小显示，仍落在原图对应点。用横图、竖图及留白检验坐标换算，点击留白不生成点。记录已知点的像素位置对照，偏差在 5 个显示逻辑像素内。
- [ ] 移动一处、改字、删除一处，另一处位置及文字保持原值。A/B 同色路线及不同照片的标记独立；取消更换保留原标记，确认换图或移图后旧点不叠在新图。
- [ ] 无图、原图缺失、写失败及迟到回调均有可见处理；离线和普通清缓存后仍能重开已保存标记。操作前后主图字节、把次、备注和自测原值一致。

## 建议验证命令

node --test tests/training-photo-marks.test.cjs

## 测试与人工验证边界

离线断言稳定 ID、读写与异常恢复。开发者工具通过真实页面入口复验，记录界面、持久值和候选 SHA。负责人用自己的手机在新候选统一验收；设备、照片方向和实际跨日结果按实测记录。

## 回滚办法

在隔离分支撤回本单实现，复跑前序节点测试。保留原有数据及本单已写的独立记录，旧版本按其支持的字段读取。
