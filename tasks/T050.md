# T050 把最新把次纠错收进更多并保留原行恢复

[整项验收](../docs/product/单线逐把紧凑布局-整项验收.md)

## 背景与问题

把次压缩后仍须找得到结果更正和误记撤回，动作要准确绑定原把并能回到原位置。

## 开发范围（允许修改）

最新卡右侧「更多」只显示当前把次的原规则允许动作。合资格完攀用「改为未完成」并说明本场把数保持，符合原规则的最近一把用「撤回误记」并说明本场少一把。撤回后原行显示「已撤回」与「恢复」。较早的合资格完攀由自己的详情发起更正。复用确认、原把校验、现有失败重试和连点保护。320/390 宽度下菜单各项保持独立点按区域。

## 禁止变更

保留更正、撤回、恢复资格和计数规则，保留原把次、序号、备注、视频、抱石锁定及绳攀重复记把。保持历史、照片、统计和存储模型。

## 验收标准

- [ ] 最新把次的菜单不出现不适用动作。取消更正不写盘，更正成功只改结果，总把数不变、完攀少一。较早合资格完攀保持从原行详情更正。
- [ ] 撤回最近一把后有效计数少一，原行显示已撤回与恢复；恢复后加一，原 ID、序号、备注和视频一致，其他场和线保持。
- [ ] 测试切菜单、选错行后取消、重复点按、失效确认、失败重试和重开。相同操作按现有规则只落一次，原行显示可用的失败或恢复动作。

git diff --check
~~~

## 测试与人工验证边界

离线核对动作资格、四个 ID、拒绝过期事件和失败重试；两宽原生与手机验证菜单触控、更正、撤回恢复及原位回读。

## 回滚办法

回退菜单和行内接线，复核原更正、撤回和恢复入口。保留已存把次状态及媒体。
