# T037 本场统一线路列表、返回换线与整项视觉对齐

## 背景与问题

T034–T036 已给小结、清单、记录、逐把明细和资料提供各自的去处。本单完成本场首屏和统一视觉，换线采用负责人认可的「回列表、再点一条」。 [整项验收](../docs/product/训练页信息层级重整-v0.2-整项验收.md)

## 开发范围（允许修改）

先读前三单、`pages/index/index.js` 和 `training-session` 目前的开场、选场、加线及关联失败重试。沿用原首页开始/继续 URL 和 `training-session` 路由，首层仅保留场次上下文、统一行列表、加线和小结。成功创建或选已有线后直达单线，导航失败可以重进原对象。限定首页变更为训练入口与清单行；其他页面只在本需求内对齐原生导航、视觉与可用性。

## 禁止变更

不再引入单线页内的第二套换线列表，不把明细、照片、小结或清单以折叠长页代替各目的地。保留顶部/系统返回、现有 tabBar 和旧资料直达，禁止改全局色板影响其他业务页。仅替换与新导航明确冲突的旧 UI 测试，计数、故障、触控和归属断言迁移至对应目的地。

## 验收标准

- [ ] 从首页开始/继续或重开先见本场列表。空场有「添加第一条线路」；0、1、4+ 条均一线一行，可从整行打开。每行有名称、等级、类型、本场有效把数和适用的文字状态。含零把、跨天锁定、同色同级、长名，均按长期 ID 区分。
- [ ] 选已有线复用原关联；新建路径保留三类与 V／YDS 联动。取消无新增，重复点击或选中失败后重试无重复。成功直达所选线的结果区域。A 返回列表改选 B 后只给 B 记把；系统返回、首页重进、同日切回旧场或无选中态都能再选原线，导航栈不因反复换线而持续增长。
- [ ] 同宽的列表行、深色标题、白色内容区、浅灰背景和细分隔线贯穿训练动线；墨绿主操作，橙色完攀，适用状态有文字。检查常用行、结果、撤回/恢复与导航命中区的 44×44 逻辑像素，以及 320/390 下长名、长备注、失败提示与按钮无覆盖。两次在相同坐标快点仍只产生一个有效动作。
- [ ] 集成时使用合成旧 v1 档案走完验收表 A–F 的离线部分。从真实新入口验证资料、照片及卡点、按原 sessionId 小结和首页单行清单；旧云汇总、统计与试用工程排除的既有回归保持。保存四个开发提交与最终 SHA 交 PM。
