# T024 原生播放、替换预览及移除操作

[整项验收](../docs/product/逐把视频本机回看-v0.1-整项验收.md)

## 背景与问题

视频页同时承接待确认预览和本机持久副本的回看。替换取消后应能返回原片。

## 开发范围（允许修改）

先读 T023 视频页及 `devtools/media-check` 的播放事件处理。接原生 `video`，支持播放、暂停、错误提示和重选。区分临时预览与当前已保存版本。接好由 T026 实现的提交、更换和移除接口，成功状态以持久层提交或可靠读回为准。

## 禁止变更

系统相册原件、训练结果、备注和其他把次的关联保持原值。播放器只接本机路径，手工时间点归 T025。

## 验收标准

- [ ] 待确认与已保存片源均可播放、暂停。缺失或损坏的文件显示可重选提示，原把次仍可访问。
- [ ] 更换先预览，取消回到同一旧片。迟到的 ready/error 或写入回执不能覆盖另一片源、把次或页面。
- [ ] 更换与移除经明确操作，忙碌、失败和成功有对应状态。返回明细和历史后按已提交关联刷新。

## 建议验证命令

~~~powershell
node --test tests/attempt-video.test.cjs tests/attempt-video-playback.test.cjs
node --test tests/*.test.cjs
git diff --check
~~~

## 测试与人工验证边界

离线核对播放器事件、回执、替换与取消。本单可注入持久路径，整项 QA 必须使用 T026 实际写入的副本。开发者工具和手机实际解码证据单列。

## 回滚办法

候选内按依赖逆序回退本批代码并复跑原训练主流程。保留已有本机视频副本、索引、相册原件和训练档案。
