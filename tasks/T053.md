# T053 接通本机历史整卡与本日场次长按

## 背景与问题

接续 T052。先读现有 `goToSessionSummary`、`switchSession`、两页渲染刷新，以及首页与统计的 `onShow`。本机训练历史短按打开原场小结，场内本日场次短按切换。两个入口共用确认流程和删除协调器。

## 开发范围（允许修改）

将长按事件绑在整卡和整个按钮根节点，使用该节点的原档案 ID 与场次 ID。长按松手不误触短按，下一次独立短按照常。单场仍显示「本日场次」按钮。第一步显示「删除场次」菜单，第二步显示原日期、岩馆、场次和最新删除范围。菜单取消、确认取消及原生调用失败均处理，遇到非取消的原生错误给出可见反馈。计数过期则用新范围再次确认，禁止沿用过期确认。更新本页列表与错误/重试状态，复用已有档案重读使首页、历史、小结、统计显示同一结果。

## 禁止变更

保留历史整卡短按、小结原归属和本日按钮切场行为。保留云汇总、分页、下拉刷新、线路照片及逐把长按删除规则。业务删除通过 T052 的统一入口，不在页面直接写存档、清理文件或另外维护编号。

## 验收标准

- [ ] 两处分别覆盖空场与记录场，框内文字及边缘可触发菜单，长按松手时不导航或切场。单场也具备入口。短按恢复原行为。
- [ ] 取消菜单和取消二次确认均无写入。确认内容正确显示日期、岩馆、场次及适用统计。连续点击只执行一次。确认后刷新两处列表、首页继续本场和小结，删除后显示正确编号和当前场。
- [ ] 菜单/弹窗失败、档案变化、待办阻塞和清理待重试均给出可见反馈。保留旧云列表和另一场次回看。
