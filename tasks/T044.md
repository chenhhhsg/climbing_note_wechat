# T044 训练线路、场次和把次使用独立卡框

[整项验收](../docs/product/界面改版-v1.1-整项验收.md)

## 背景与问题

线路与把次主要用连续分隔线，相邻条目和同色同级线路的身份不易辨认。

## 开发范围（允许修改）

本场和小结一线一卡，底栏记录一场一卡，均用中性细边框并留卡间间距；日期、岩馆和线路身份放在对应标题或卡内，已选线路用短文字或边缘标记。逐把一把一框，完攀用深绿，未完成用深橙，采用对应描边、浅色底、深底白字并写明状态。供 T045 在现场复用。

## 禁止变更

保留路由、列表数据、稳定顺序、选线行为、场次分组与统计。范围限当前列表和卡框，首页、底栏名称和全局主题沿用现状。

## 验收标准

- [ ] 同色同级和长名称线路在本场及小结均一线一卡，点行仍对应原线路，选中标记可辨且顺序稳定。
- [ ] 底栏继续日期倒序、同日按岩馆分组，同馆多场各一中性卡，点卡传原场次 ID。
- [ ] 逐把的两个结果都以高对比配色及文字区分，320/390 宽度下长名称、卡框及入口可读可点。

## 建议验证命令

~~~powershell
node --test tests/training-screen-hierarchy.test.cjs tests/training-session-summary.test.cjs tests/record-list.test.cjs tests/session-route-flow.test.cjs
node --test tests/*.test.cjs
git diff --check
~~~

## 测试与人工验证边界

离线验证 WXML 绑定、行身份和顺序。开发者工具及手机核对 320/390 宽度的间距、配色和点击范围。

## 回滚办法

按集成依赖逆序回退显示样式，保留场次、线路和把次原数据。
