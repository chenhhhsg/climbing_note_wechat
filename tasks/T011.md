# T011 独立试用工程添加线路照片、跨天预览、更换与移除

## 背景与问题

依赖 T010 QA PASS 的持久照片服务，将其接入已验收的今日攀爬、线路详情和历史入口。用户已确认本批先做独立试用，正式账号隔离和真机专项另列验收。本轮对应 LP01–LP06、LP08–LP10 的界面行为及 LP14 的缺图展示。

先读产品验收文档、T010 README 契约、`pages/today/`、`pages/route-detail/`、`utils/store.js` 与已存在的照片/原回归测试。实际起点须包含 T010 已审提交，不能从缺少依赖的 main 重新开发。

## 开发范围（允许修改）

- 在独立工程的新建线路、今日当前线路、历史选线、线路详情加入一张可选主照片的入口与展示，沿用既有视觉和底部记尝试按钮。
- 接入拍照/相册选择、预览确认、压缩保存、保存状态、失败重试、更换、移除确认和缺文件提示；列表用缩略图，详情可打开完整主图并缩放。
- 使用 T010 持久服务，不另做一套路径数组。试用身份和数据集来源须集中、稳定并明确为虚构；必要时给旧试用缓存补兼容的数据集标识，保留所有原记录和尝试。
- 核对现有“重置试用数据”：有照片时提示其属于用户资料；本轮可阻止会丢关联的重置并提供可操作说明，或实现经确认的安全重置。不得静默重用 route ID 后挂上旧线路照片。普通清缓存与容量管理在 T012 完成。
- 更新 README 的操作步骤、测试和执行报告；内部服务只允许为本轮接入做必要兼容，不重构无关逻辑。

## 禁止变更

不改独立工程 AppID/项目配置、正式页面/路由、根打包配置、云初始化、真实账号或旧记录。照片不是必填项，不把多张照片或云上传带入首版。不覆盖 T010 的归属/失败恢复契约，不删除既有回归或降低断言。不得借试用身份宣称真实账号隔离通过。

## 验收标准

- [ ] **PU01 可选与选择**：不添加照片也能建线、记两把和备注；相册与拍照两种请求参数正确。选择后预览并确认才保存；取消、权限拒绝、压缩/保存失败保持原线路可用。照片操作不锁住记尝试功能。
- [ ] **PU02 状态与单图**：无图、保存中、已存、失败可重试、文件缺失有清晰状态；文件和索引完成前不显示成功。首次成功提示“已保存到本机”，页面标明本机试用；每条线最多一个有效主照片引用。
- [ ] **PU03 四处一致与跨天**：L1 周四两把、周日一把的历史/当前/详情显示同一主图；缩略图指向该主图，主图可预览。L2 同色同级不串图；第二把备注与两天三把统计保持。重进页面仍从持久关联恢复。
- [ ] **PU04 更换移除**：更换失败仍显示并可预览旧图，成功后各入口一致；移除本机唯一副本前说明需重新添加，取消不变，成功后可补新图，失败不虚报成功；所有尝试和旧汇总边界保持。
- [ ] **PU05 页面交错**：给 L1 保存时切 L2、退出/重进、编辑备注或继续记尝试；完成回调只刷新正确归属，不回写旧页面快照、不丢后续记录。以真实页面方法复现并分别断言照片索引、线路和尝试。
- [ ] **PU06 实际走查与回归**：在开发者工具导入实际候选，走完选片确认、两把、备注、跨天回看、更换、移除及缺图提示。可用生成素材或 mock 原生选择器返回值，明确模拟的步骤；持久保存调用真实文件适配器。完整测试通过且无跳过，证据含截图、操作步骤及实际候选提交。

## 测试与人工验证边界

本轮必验为页面真实方法、持久照片服务集成及开发者工具走查。真机拍照/相册权限、退出微信后的保留与压缩后岩点识别另列待验；实际微信账号隔离、正式入口与云端同步均未接入。最终功能交负责人在 T012 集成候选一并验收。

## 回滚办法

保留 T010 已审提交，撤销本轮页面接入可恢复无照片入口的既有试用界面；照片文件和索引继续保留，不能因旧页面不展示而清理。旧试用缓存迁入新数据集标识前留兼容恢复依据，不改写正式记录。
