# T034 按原场次打开独立的本次小结

## 背景与问题

目前小结和历史场次选择器都在场内长页。先把小结移到独立页，后续列表只需传入用户打开的场次。 [整项验收](../docs/product/训练页信息层级重整-v0.2-整项验收.md)

## 开发范围（允许修改）

先读 `utils/training-session-summary.js`、`utils/training-wishlist.js`、`pages/training-session/training-session.js` 及其小结绑定。注册 `pages/training-summary/training-summary` 原生页，从场内的小结入口传入 archiveId、sessionId，使用 `buildSessionSummary(archive, sessionId)` 和已有清单成员读写。保留历史场次只读回看、当前场返回和小结勾选操作。替换原内联小结，保留其余训练操作。新目录仅包含该页四件套。

## 禁止变更

不更改统计口径或 v1 存储结构，不在读小结时选场、改选线、开场或结束训练。G09、V05、PK03 仅添本单新路由及正式包预期；其他旧测试仅迁移小结入口及对应断言。

## 验收标准

- [ ] 同日 S1/S2 含不同把数，另有昨天 S0。打开 S1 后重显、返回或查看 S0，显示的场次、已爬线路数、有效把数、完攀把数及各线分项均与指定场次一致。单纯打开和返回前后档案字节一致。
- [ ] 撤回、恢复和改为未完成后分别对账；待保存把次不计。空场能进入小结并看到空态；未知或串档的 sessionId 给出可见状态，不能展示另一场。
- [ ] 从小结把一条未完成线加入或撤出想爬清单；重复点击仍为同一原 routeId。清单写失败可重试，单纯回看不改清单。
- [ ] 场内只留小结入口；新页在正式 app.json 中恰好注册一次。保持所有原页面、tabBar、包内必需文件及缺文件负例。

## 测试与人工验证边界

Node 用合成的旧档、同日两场、跨天和异常存储，从真实路由参数运行页面逻辑。模拟器和手机检查跳转、返回和可读的分项排版，证据纳入本批统一 QA。

## 回滚办法

隔离分支回退本页路由注册和入口替换，恢复原小结展示；用同一 S1/S2 夹具核对数据与回退前一致。
