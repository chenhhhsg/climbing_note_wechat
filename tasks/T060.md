# T060 R5 旧云表单保存成功后的终态

## 背景与问题

按 2026-11-20 复审交接执行。以上一通过自测的任务作为集成前置，验收绑定本批最终提交。

## 开发范围（允许修改）

成功后将页面提交锁定至返回，单个延迟返回回执。返回失败提供显式返回，保存仍保持锁定；确定失败才允许重试。保留旧入口。旧云图片清理本批后置，未知云写入结果不删除文件。

## 禁止变更

保留现有页面结构、试用资料、已验收归属、普通清缓存保护及未涉及的行为。禁止改动 AppID、实际 CloudBase 配置与权限，禁止在生产档案或真实云端注入故障。合并和发布由负责人另行授权。

## 验收标准

- [ ] 模拟云成功后连点，实际云写入和延迟返回各一次。返回失败时可重试返回，重复保存零写。
- [ ] 失败后允许重试原表单，离开页面清理返回计划，原输入与既有上传路径保持。

## 建议验证命令

```powershell
node --test tests/*.test.cjs
git diff --check
```

## 测试与人工验证边界

先用合成档案、严格微信参数对象及可恢复故障验证。按分批验收单在同一冻结提交复核适用的原生页面、正式构建和手机待验。

## 回滚办法
