# T040 将线路照片动作标记移到独立大图页

[整项验收](../docs/product/线路历史与照片动作标记-v0.1-整项验收.md)

## 背景与问题

线路历史内的原图、标记及编辑区挤占逐把记录。历史只展示缩略图和当前照片的标记数量，大图操作进入二级页。

## 开发范围（允许修改）

注册 `pages/training-photo-marks/training-photo-marks` 原生四件套。历史有图时显示可点击缩略图和「照片动作标记 · N 个」，无图时保留已有添加入口。二级页按原档案、线路、照片 ID 重新读取当前版本，用现有 `training-photo-controller` 及 `training-photo-marks` 处理主图、标记和相对坐标。迁移当前标记交互，支持点岩点、选手法或脚法、写提示、保存及编辑、移动、删除。把有图时的换图与移除入口放在二级页，复用既有确认、失败和空间提示。有草稿返回时提示确认，历史 `onShow` 读回最新数量。图暂不可用时可读该版本的提示文字，恢复图后再定位。

## 禁止变更

不改照片索引、持久文件格式、标记数据结构、版本规则和坐标基准，不写回旧档，不将样稿 HTML、照片和合成素材放进正式包。保留逐把更正和视频入口的原归属。

## 验收标准

- [ ] 历史有图时只展示缩略图及标记入口，数量按当前照片版本计。二级页初次进入渲染同一张主图及已有标记。可添加、编辑、移动和删除，返回历史立刻刷新数量。撤销未保存草稿时既有数据、数量不变。
- [ ] 横图、竖图和至少两种视口的实际图片边界之外不可新增或移动标记。重开及尺寸变化后同一归一坐标仍指向原图岩点。图片缺失时有可见提示，可读取已有标记文字。
- [ ] 取消换图保留原图和原标记，确认换图仍按原照片版本规则读取，新图不叠加旧图坐标。换档、同名线路切换、旧图迟到按钮或测量都不能给另一张图写入。读失败、写失败和恢复走既有提示。
- [ ] 保留原照片添加、更换、移除和清缓存保护。新增路由及运行文件入正式包，旧路由、tabBar、试用目录排除及缺文件断言通过。只迁移随页面位置变更的测试入口。

## 测试与人工验证边界

离线用现有存储夹具核对照片与标记归属和坐标。独立原生 QA 用横竖合成图量取实际显示框并实点，负责人复验真机照片、返回、换图及重开。

## 回滚办法

在集成工作区按依赖逆序撤回本任务代码，复跑原训练页、视频和照片入口。保留已存训练、照片、标记和视频数据。
