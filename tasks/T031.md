# T031 在结果按钮旁切换本场线路

## 背景与问题

正式页面的本场线路列表位于照片、记录、小结与清单之后。频繁换线时，用户需要滚动很远才能记下一把。 [整项验收](../docs/product/场内操作简化-v0.1-整项验收.md)

## 开发范围（允许修改）

在结果按钮附近显示可点的本场线路名、当前选择和等级。参照样稿，有 1–3 条时直接展示；超过 3 条时展示当前线及最多两条不重复的近期线路，提供「全部 N 条」。从列表返回后原地记结果。照片、逐把记录、备注、小结和下次想爬保留可见入口与原上下文。

## 禁止变更

复用本场与本馆的现有 ID 及选择逻辑，不建立第二套存储，不改变照片、清单、场次归属和已完攀规则；不调整其他页面布局。

## 验收标准

- [ ] 同馆 A、B 同色同级，分别点击线路名。线路名、等级、已选态、把数和照片一起切到对应 ID；在 B 记一把和备注只改变 B。选线本身不创建路线、关联或把次。
- [ ] 至少 4 条线时，短列表包含当前线，「全部 N 条」按真实本场关联计数；所有本场线都可选，其他场次独有线不出现。返回或取消不改当前线。
- [ ] 近期线路和长名称在 320、390 两档均能操作。首次与已有照片/长历史场景，全线入口和结果按钮可找到，附属内容不挡操作。
- [ ] 选择失败可重试；快速 A→B 后旧照片回调不覆盖 B，下一把只归 B。重新打开同一场次恢复持久化的当前线，并能按原 ID 查看逐把记录、小结及清单。

离线验证选中身份、归属、过期回调和已有入口。模拟器通过真实名称和「全部 N 条」操作，核对滚动、按钮边界和图片。
