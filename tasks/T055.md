# T055 整理逐把视频原生播放和操作区布局

## 背景与问题

负责人补充要求，接续已通过手机验收并合入的 T025 候选 `1e14cb771e4b`。现在逐把视频页的标题、画面外播放按钮、重选和保存说明重复，视频占用挤在页面前段。调整同一页面结构及原入口提示，和长按删除批次统一验收。

## 开发范围（允许修改）

正常回看按把次信息、原生播放器、紧贴其下的同排「更换视频／移除视频」、时间点、页尾占用布局。精简重复标题及说明，取消画面外大号播放/暂停按钮并更新相应提示。保留画面原生播放、暂停、进度和全屏操作，保留 T025 的内部状态和 `#video-player` 定位及实际原生节点回报。已有视频共用「更换视频」一个选片入口；找不到、打不开或报错时仍可更换。待确认的更换与取消在同一区域，首次选片只有一个入口，随后可在同一区重选或保存。已有移除确认保留。页尾完整保留占用、提示和无引用副本清理，适配 320/390 CSS px。

## 禁止变更

保持原把次归属与保存位置、相册原片、普通清缓存、原生事件、时间点读写生命周期、冷启动点回和共享文件所有权规则。禁止改动视频存储和删除协调器、其他页面、云配置、AppID 或把已保存视频迁移。

## 验收标准

- [ ] 主体顺序正确、替换/移除同排，重复选择和画面外播放按钮已移除；丢失/不可定位/播放报错有可见提示和原更换入口。页尾找到完整占用和清理区。
- [ ] 首次相册选择、取消、预览重选和保存通过；已保存视频更换取消保留旧片及时间点，确认后替换新片；移除取消保留原片，确认只移除攀笔副本。
- [ ] 用视频画面原生控件播放，在原把记点、点回、移除时间点。冷重开从原场直接点，核对实际画面误差仍 ≤0.5 秒。测试只改旧视图契约，保留存储、时间和归属断言。
