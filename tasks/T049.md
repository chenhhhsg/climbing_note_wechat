# T049 为最新卡和旧把详情接原把视频入口

[整项验收](../docs/product/单线逐把紧凑布局-整项验收.md)

## 背景与问题

视频入口要能在紧凑布局中一眼找到，展开旧把后还要能区分该把是添加还是回看。

## 开发范围（允许修改）

最新一卡的备注右侧放「＋ 添加视频」，有片在同位置显示「回看视频」。旧行收起仅已有视频时出现小视频图标，点开原把后可添加或回看。复用现有逐把视频页、关联读回与本机保存。视频页可见说明写清「视频保存在这台手机的攀笔中」，与已存在的预览、确认和相册保留说明一致。

## 禁止变更

保留原播放器、视频索引、片段、缓存、容量、保存和权限口径。保留本机文件及原相册，不引入云上传、时间点或视频页重排。

## 验收标准

- [ ] 最新卡添加/回看两态位置一致。旧行无片时无视频图标，有片时图标只出现在原行；展开后按该把的真实关联给添加或回看入口。
- [ ] 给最新一把和较早一把分别保存不同视频；核对原档案、场次、线路及把次 ID，切换卡层级或重开后能从两把各自播放原片。
- [ ] 取消选片或替换、失效点击和回执迟到按原规则处理，其他把次、备注、原文件与索引保持。无片及保存前提示明确本机存储位置。

## 建议验证命令

~~~powershell
node --test tests/attempt-video.test.cjs tests/attempt-video-playback.test.cjs tests/session-route-flow.test.cjs tests/training-flow.test.cjs
node --test tests/*.test.cjs
git diff --check
~~~

## 测试与人工验证边界

离线查原四个 ID、视频索引及取消分支。原生与手机使用不同样片实际选择、保存、断网重开和从原把播放。

## 回滚办法

回退视频入口和说明文案，已保存的本机视频和关联沿用原路径。
