# T013 新建线路的攀岩类型、等级联动与旧线路兼容

## 背景与问题

试用工程的 `store.GRADES` 固定为 V0–V8，`createQuickRoute` 用选项索引取等级。正式工程的 `utils/grade.js` 已有完整 V 级与 YDS 表。先读两处实现、今日页的新建及照片流程、详情页的线路展示和 G04/G05 测试。

## 开发范围（允许修改）

在 frontmatter 列出的试用工程文件内增加类型和适用等级读取、创建校验、选择器和列表/详情展示。需要抽取共用规则时可新增 `utils/route-rules.js` 于试用工程内。正式等级表只读参照，试用工程单独导入开发者工具时须能运行。照片测试文件仅用于适配和验证快速新建流程。

## 禁止变更

正式小程序、云端、AppID、试用存储键、长期线路 ID、照片文件与索引均在范围外。保留旧试用数据和损坏数据原有处理，不进行批量回写或重置。

## 验收标准

- [ ] 新建表单在名称旁保留可选照片，颜色可独立选择。攀岩类型在左、等级在右，三种类型名称与计划一致。等级选项及顺序按正式等级表核对。
- [ ] 按整体验收 A3 操作，V3 切顶绳清空，顶绳 5.10a 切先锋保留，切回抱石清空。失效时显示「请选择等级」。在空值、越界或类型与等级错配时直接调用创建入口，线路数、活动线路和照片绑定均不变，也不能静默回落到首个等级。
- [ ] 分别保存抱石 V3、顶绳 5.10a、先锋 5.11b，重新进入后类型、等级、颜色和长期 ID 稳定。可不加照片，已有选图的「创建并选中」继续将照片绑定到新线路。
- [ ] 缺类型的旧 V 级线路可按抱石读取。以旧备注和照片关联为夹具，打开新版本前后归属、原把次与 ID 一致，浏览操作不触发迁移。记录新旧等级选项和创建前后状态的可复跑断言。
