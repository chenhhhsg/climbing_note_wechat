# T041 把线路主照片入口接到单线记录首屏

[整体验收](../docs/product/现场记录与历史回顾-v0.1-整项验收.md)

## 背景与问题

现场需要在记把时就地留一张线路照片。当前单线页只链接到线路资料，主要照片动作在下一级。

## 开发范围（允许修改）

单线记录首屏放一行照片入口，保留两种记把动作和最近一把。无图提供「添加线路照片」，有图显示缩略图。复用已存在的照片控制器和预览确认流程，支持相机或相册、取消重选、失败提示。打开已有图走原二级照片动作标记页，按本机档案、长期线路和当前照片版本校验。历史及现场回读同一主照片及标记。在本任务涉及的现场入口和提示中，将「线路资料」统一为「线路历史」。

## 禁止变更

保留现有照片索引、压缩保存、换图、清缓存保护和标记坐标规则。保留逐把备注、视频和更正归属。新建线路仍按现有流程先创建并选中，再在单线页添加照片。

## 验收标准

- [ ] 无图和有图显示对应的紧凑入口。选图后预览，确认后持久读取同一照片，取消或写失败保留之前状态。
- [ ] 为 A 线添加照片，现场、历史及已注册二级页使用同一档案、线路和照片 ID。进入已有标记、返回及重开后，当前版本标记数量和坐标一致。
- [ ] 同名 B 线、切档及迟到选图回调保持隔离。取消换图保留原图与卡点，确认换图遵循原版本规则。记把、清缓存保护和既有标记测试通过。

## 建议验证命令

node --test tests/training-flow.test.cjs tests/training-photos.test.cjs tests/training-photo-marks.test.cjs tests/training-screen-hierarchy.test.cjs tests/session-route-flow.test.cjs
node --test tests/*.test.cjs
git diff --check
~~~

## 测试与人工验证边界

离线核对两个页面的照片归属和读回、回调时序及标记数量。开发者工具核对首屏、横竖图和真实选图。手机实测拍照、确认、打开同图卡点及退出重开。存储与识别均在本机。

## 回滚办法

按集成依赖逆序回退任务提交，复跑现场记把、线路历史和标记页读取。保留所有本机照片、标记、训练与视频。
