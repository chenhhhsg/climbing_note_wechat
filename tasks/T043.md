# T043 底栏记录按日期与岩馆显示原场小结

[整体验收](../docs/product/现场记录与历史回顾-v0.1-整项验收.md)

## 背景与问题

底栏「记录」的本机区当前按长期线路聚合，用户回看一次训练需要先定位线路。

## 开发范围（允许修改）

将底栏本机训练历史改为原场次列表。按训练场次的原日期倒序，同日按原岩馆 ID 分组，场次用现有场次标识和小结计数。组内按原场次顺序倒序，同日岩馆组用组内最新场次决定展示顺序，保持稳定。一场一行，包含原场次标识、线路数和有效把数，零把以现有空场小结口径显示。点行直接用原档案 ID 和场次 ID 打开现有小结，从小结继续回看原线路和原场上下文。展示层复用已存在的只读小结计数，保留旧记录入口和加载行为。

## 禁止变更

保留场次、日期、岩馆和线路 ID 的存储格式以及现有计数逻辑。浏览不选择或创建活动场次，不写档案、不切换当前线路。保留旧记录的原 ID、分页重试及下拉刷新竞争处理。现有测试只更新被替代的本机展示契约，保留训练统计、撤回恢复及旧记录行为断言。

## 验收标准

- [ ] 两个日期、同日两家岩馆（允许同名）、同馆两场及跨午夜场次的夹具中，日期倒序且组与行不串。跨午夜按原场次日期归组，每个原场次 ID 恰好一行，摘要与该场小结一致。
- [ ] 点不同场次行进入各自的小结。查看旧场线路时仍看到原线、同一主照片和跨天历史。返回首页继续原活动场、原活动线路，浏览全过程本机档案无写入。换档或场次不存在时按既有错误路径处理。
- [ ] 旧云列表仍以原 ID 打开旧记录详情。断网、无权限或云分页失败时本机场次列表与小结仍可读取。原刷新竞争、空态、撤回恢复后计数和小结测试通过。

## 测试与人工验证边界

离线用原始日期和 ID 核对分组、数量、导航以及打开历史前后的存储字节。手机复查底栏一行直开、旧场回看后继续当前场。旧云权限核验沿原队列跟踪，本任务回归既有读接口和离线错误路径。

## 回滚办法

回退本任务的列表展示和导航提交，复查旧记录与原场小结。沿用当前本机训练数据。
