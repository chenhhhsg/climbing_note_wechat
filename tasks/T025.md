# T025 记录视频时间点并从历史回到对应画面

## 背景与问题

在复盘某一把时，用户要记下动作发生的位置，下次从这把返回片段中的同一时刻。既有验证工程已探索第 5 秒跳转。 [批次验收](../docs/product/手机反馈与逐把视频-批次验收.md)

## 开发范围（允许修改）

在当前视频页通过播放器的实际时间添加、列出、点回和移除该片段的时间点。持久记录使用毫秒、把次和片段标识，调用原生 seek 时换算为秒。

## 禁止变更

不生成教练建议或 AI 报告，不伪造画面落点；截图、样片不打入正式包。

## 验收标准

- [ ] 在 B 的片段记下 5 秒，重开后仍有 5000 ms；从历史点回时播放器请求约 5 秒。30 FPS、60 FPS 的带可见时间码样片均可核对实际画面，目标差值不超过 0.5 秒。
- [ ] 覆盖 0 秒、片尾、元数据未就绪、片源不可用与错误时间值；不能写入越界或非有限时间。迟到事件、A/B 切换和连续操作都不能把标记写到另一把或另一版片段。
- [ ] 更换不同片段后不会显示旧片的时间点。删除单个时间点不会删视频、别的时间点、训练结果或备注。保存失败可重试，无重复写入。

## 建议验证命令

~~~powershell
node --test tests/attempt-video-markers.test.cjs
node --test tests/*.test.cjs
git diff --check
~~~

## 测试与人工验证边界

离线核对毫秒、秒和幂等；开发者工具分开记录 seek 请求与视频画面的烧录时间，手机微信实际解码落点由负责人复核。

## 回滚办法

在隔离候选中按依赖逆序撤回本单的实现，复跑前序用例。保留已存在的持久媒体、用户记录和索引，回退版本只读取其支持的格式。
