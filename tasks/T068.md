# T068 备份交付 个人页文本导出、诊断与确认恢复

## 背景与问题

按 2026-11-20 复审交接执行。以上一通过自测的任务作为集成前置，验收绑定本批最终提交。

## 开发范围（允许修改）

在个人页既有结构内提供文本导出、文本输入、摘要预演、明确的正式恢复确认和受损诊断导出。使用 T067 接口验证，失败/取消不改活动数据；剪贴板回执按真实成功。页面说明包含和不包含的文件，释放过去输入及回执的范围受旧操作令牌保护。

## 禁止变更

保留现有页面结构、试用资料、已验收归属、普通清缓存保护及未涉及的行为。禁止改动 AppID、实际 CloudBase 配置与权限，禁止在生产档案或真实云端注入故障。合并和发布由负责人另行授权。

## 验收标准

- [ ] 在独立档案用昵称、备注、标点和不同场次回环测试；仅确认后激活验证过的文本。待验手机可保存、粘贴较大真实长度的文本。
- [ ] 无效文本和写失败时当前档案及清单仍可读；受损诊断入口可用；备份说明和媒体保留行为符合实际。

## 建议验证命令

```powershell
node --test tests/*.test.cjs
git diff --check
```

## 测试与人工验证边界

先用合成档案、严格微信参数对象及可恢复故障验证。按分批验收单在同一冻结提交复核适用的原生页面、正式构建和手机待验。

## 回滚办法

回退本批隔离分支中的任务提交并复验既有记录读取。验收资料与当前试用工程保留。
