# 手机反馈与逐把视频 · T021–T026

基线是负责人手机验收通过的正式工程 `8b28a9890a234523e68daef9be4b42ffba5af5de`。2026-11-10 负责人决定优先安排即将提交的 UI 需求。T021–T022 保留草案，T023–T026 视频任务暂缓。下表保留原拟范围和验收场景，供后续排期参考。

| 顺序 | 用户能做什么 | 验收读数或可见结果 |
|---|---|---|
| [T021](../../tasks/T021.md) | 在体能自测完整阅读体重、指力与拉力负重栏 | 窄屏及大字体下可读提示、`68.75`、`12.5`、`0` 与 kg；原 60 kg 样例仍得 20 分。仅修正已定位的同日两场测试日期。 |
| [T022](../../tasks/T022.md) | 从底部统计查看本机训练 | 两次未完成、一次完攀显示 3 把、1 完攀，更正后为 3 把、0 完攀；保存自测成绩后数字一致。 |
| [T023](../../tasks/T023.md) | 从场内或历史中选中已保存的某一把，为它从相册选片、确认关联 | 同线两把 A/B 仅 B 出现视频。选片取消或保存失败不改变原把；无需视频也能完成记录。 |
| [T024](../../tasks/T024.md) | 在 B 的详情播放、暂停、重开后恢复可用片源；临时文件失效时可从相册重选 | 原片不可读时显示「需重新选择原片」，仍可看把次与备注。重选、替换或解除关联只影响 B。 |
| [T025](../../tasks/T025.md) | 在播放时记一个时间点，次日从 B 点回同一画面 | 使用带烧录时间码的 30/60 FPS 样片核对第 5 秒，保存毫秒值，实际画面落点与目标差值不超过 0.5 秒。换成不同片段时只展示新片的时间点。 |
| [T026](../../tasks/T026.md) | 主动选择「保留本机回放副本」，重开仍可离线回放，也可移除副本 | 默认使用临时片源。明确选择后才写入小程序持久目录；取消、空间不足或中途写失败时，已有副本及把次仍可读。普通清缓存保留在用副本。 |

## 数据与交付

视频关联按本机档案 ID、已保存的把次 ID 和片段 ID/版本区分。元数据、时间点与可选副本使用独立的本机视频命名空间，原有训练、线路照片和自测沿用现有位置。测试使用虚构场次与合成样片；正常试用不要求上传相册内容。私有上传、服务端鉴权、任务处理与 AI 保留在后续排期。

使用独立工作区，依次给 ZCode 运行 `run-approved-task.ps1 -DevOnly`，核对代理和测试的真实退出码、全量测试与批准路径。独立 QA 在固定候选复跑两项反馈和完整视频操作，覆盖取消、重试、跨线、重开、文件丢失及空间不足，检查正式包包含视频页并排除开发素材。分别记录模拟器实际画面、离线注入证据和待负责人手机验证的选片、微信大字体、真机播放器及文件配额。合成样片和截图留在测试证据目录。

负责人离开期间可在已批准范围内返工和复验。若某一步缺真实设备或云环境，记录具体待验项，继续可独立验证的工作。保留原手机验收候选、试用数据和其他窗口的改动。新候选交负责人验收后再收尾。
