# 攀笔 · 本机训练场次长按删除

负责人已批准修改单。按现有产品队列接在 T025 之后。规划时本地 `main` 为 `57fedbfc8e6a`，进入开发时以届时主线重新核对基线和修改范围。原修改单见 [本机训练场次长按删除修改单](../../../攀笔_本机训练场次长按删除修改单.md)。

## 负责人确认的操作

- 「记录 → 本机训练历史」的整张场次卡和「场内记录 → 本日场次」的整个场次按钮均响应长按，包括框内空白。当日只有一场也保留按钮。短按仍分别打开原场小结、切换到该场。长按松手不执行短按。
- 长按先显示操作菜单。选择「删除场次」后，才显示二次确认。确认写明原日期、岩馆和场次。有记录时列明线路数、有效把数及视频关联数，有已撤回的把次时说明它们也在范围内。提示会一并移除本场把次和备注，并清理没有剩余引用的攀笔视频副本。空场只需确认删除该场。关闭菜单或取消确认都保持数据和当前场不变。
- 确认以本机档案 ID 与原场次 ID 为准。确认框打开后如果归属或内容发生变化，重新读取。目标仍存在时显示最新范围供再次确认。目标已不存在或档案已切换时结束当次操作。待保存、撤回、恢复、更正或附件等操作在途时提示先处理。

## 一次候选验收

| 项目 | 要操作并记录的证据 |
| --- | --- |
| S1 · 双入口 | 用隔离档案，从历史整卡删除一个空场、一个有记录的场。再从本日按钮各删一个空场和有记录的场，覆盖当日唯一按钮。每个入口单独核对按标题、按框内边缘、松手、取消菜单、取消确认、短按及重复确认。对照日期、岩馆、场次及数量，检查只删被确认的原 ID。 |
| S2 · 编号和当前场 | 准备同日同馆多场、同日另一岩馆及跨日场次。删除中间场后，同日序号按既有规则顺延，其他原 ID 和其他日期的编号保持原值。删除非当前场保留当前选择。删除当前场接续同日同馆最近一场，首页和本次小结一致。删到没有可接续场时回到待开始，仍需用户主动开场。同日其他岩馆可以保留，不能被自动切为当前场。 |
| S3 · 记录和媒体归属 | 在两场复用同一线路，添加线路照片和卡点。分别添加备注和本机视频，其中一场安排一个已撤回但仍关联视频的把次。删除该场后比对另一场小结、原把次 ID、备注、视频和照片标记，核对本机统计扣除目标场的有效把数和完攀。共享副本保留给剩余关联，孤立副本清理。人手从手机相册打开原片。旧云端汇总沿原入口只读回看。 |
| S4 · 失败和重开 | 注入档案写入前失败、写入回执丢失、索引读写失败、文件清理失败。写入前失败时档案与附件保持原值。提交状态未知时通过重读原档案确认。已删的场次在重开后仍缺席，待清理副本可继续重试。重复确认和迟到的原保存不能重复处理或复活记录，跨档案同 ID 保持隔离。确认框打开后将备注或视频替换为相同数量的新版本，必须刷新范围并重新确认。 |
