| 场景 | 独立 QA 证据 | 负责人手机验证 |
|---|---|---|
| H1 · 选片提示与回看 | 用同线两把的正反对照确认「保存到攀笔」的说明完整，确认成功才显示「视频已保存到这一把」。执行应用内普通清缓存，重开原把次后核对索引版本和原文件字节。错误、取消和更换仍按现有流程。 | 给一把保存本机视频，从原把次播放。说出副本在这台手机微信里的攀笔中且会占用本机空间，系统相册原片仍在。应用内清缓存后重开原把次，确认为同一视频。 |
| H2 · 原把次更正 | 用跨日、同馆多场和同名异线夹具核对资格。取消、错档、连点与写失败不改另一把，重试只改原把。成功后记录原序号、备注、片段 ID、文件字节、总把数和完攀数。 | 在线路历史点原完攀旁的「更正」，核对日期和场次。确认后该把显示未完成，总把数保持，完攀次数减一，备注、编号和原视频仍在。 |
| H3 · 大图标记 | 两个档案或两条同名线保留独立的照片和标记。核对横竖图片的实际绘制边界，点击留白不落点，移动和编辑按当前照片版本生效。保存后返回刷新数量，返回取消草稿保持原值。 | 从缩略图和「照片动作标记 · N 个」进入二级页，核对原点，分别添加手法和脚法。编辑、移动、删除一处操作后返回，数量与内容对应。 |
| H4 · 换图与重开 | 记录取消换图、确认换图、原图不可用、跨线和迟到操作。旧标记坐标仍属于原版本。在不同宽度和重开情况下比对同一个岩点。 | 先取消换图，再在测试线路上确认换图。新图无旧点，退出重开后新图与已存标记仍对应。 |
