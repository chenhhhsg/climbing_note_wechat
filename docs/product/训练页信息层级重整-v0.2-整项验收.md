## 用户在哪里做什么

| 入口或目的地 | 本页职责 | 打开与返回 |
|---|---|---|
| 首页 | 保留开始、继续场次。下次想爬仅占一行，显示名称和数量。 | 继续场次先进本场列表。点想爬行进独立清单，返回首页。 |
| 本场线路（沿用 `training-session`） | 岩馆、场次、加线、小结入口；同一种行样式列出本场每一条线。显示名字、等级、类型、本场有效把数和适用状态。零把线路也能辨认。 | 整行点入单线记录。空场点击「添加第一条线路」，选已有或新建并成功后直接进该线。返回列表再选 B 即换线。 |
| 单线记录（新增 `training-record`） | 本线结果、把数、保存与失败重试、最近一把的原序号及撤回、恢复。提供逐把明细和线路资料入口。 | 从列表带入档案、场次和长期线路 ID。返回原场列表，行读数更新。详情或明细返回原线。 |
| 本线逐把明细（新增 `training-attempts`） | 仅显示所选场次和线路的把次，按原序号、结果、备注对齐；给指定把次补、改备注。 | 保存、取消、失败重试均指向原 attemptId。返回单线记录。 |
| 线路资料（沿用 `training-route`） | 长期线路照片及卡点、跨天历史、原有更正／再记、清单管理等已有操作。 | 从单线或想爬清单按原 routeId 进入。普通返回回到来源，「当天再记」须显式选择适用场次后进入对应的记录。 |
| 本次小结（新增 `training-summary`） | 按传入的原 sessionId 读取场次、线路及有效把数、完攀，保留未完成线路加入想爬的操作。 | 从本场打开并返回原场。只读查看历史场次不会切换当前训练。 |
| 下次想爬（新增 `training-wishlist`） | 独立清单承接原岩馆分组、状态和空态，保留待爬、已完成、已归档的既有处理口径。 | 从首页打开，点原长期线路进资料，再返回清单与首页。首页数量等于现有 listWishlist 返回的本档可展示条目数，空清单显示 0。 |

## 同一候选的一次训练

| 取证点 | 实际动作与可核对的结果 |
|---|---|
| A · 加线、换线 | 从空场点「添加第一条线路」。取消时关联数不变；新建 A 成功直接进入 A，选择本馆已有 B 复用原 ID。回本场再点 B，包含同色同级、长名、零把和四线以上。核对每行把数、文字状态和落盘归属。同日再开第二场，返回第一场能选原线。 |
| B · 单线连续操作 | A 记到第 3 把，给这把保存备注。从真实按钮撤回、切去 B、重开 A 后恢复，3→2→3，ID、原序号和备注一致。「改为未完成」保留把数。两档屏宽分别对撤回、恢复在同一屏幕位置快点两次，记录按钮矩形、两次实际命中、原 ID 与计数。 |
| C · 故障与旧档 | 写前失败与写成后回执丢失分别取证；跨页原重试及延迟保存、撤回、恢复不能重复或逆转更新。换档后复用同名 ID，旧页面无法写入新档。失效或缺参入口不会改写其他记录。照片、备注、卡点与原对象对账。 |
| D · 线路规则与资料 | 昨日已完攀的抱石线今日能回看，不能新增把次；本场误完攀沿用现有纠错与恢复条件。顶绳、先锋能重复记完攀，V／YDS 对应正确。沿资料页验证空态、存入一张合成原图、添加卡点、重开、历史回看；普通清缓存后图片和索引仍可读。微信原生选图、预览取消及重选另留实测证据。 |
| E · 小结与想爬 | 用同日 S1、S2 和跨天夹具，从 S1 打开小结，切换活动场次的合成条件下重显仍读 S1。撤回项和待保存项不计入。把未完成 A 加入清单，首页单行数量随既有口径更新；同名异馆点开按原 routeId，返回原清单和首页，活动场次与旧照片不变。 |
| F · 视觉与实地 | 320、390 逻辑像素宽度均检查空态、多线、长名、长备注、失败重试、抱石锁定与返回。记录真实可用视口、原生截图、点按矩形与触发目标。白色内容区 `#FFFFFF`、浅灰页底 `#F2F4F3`、深色标题和正文 `#182421`、墨绿主操作 `#1F5948`、橙色完攀 `#FF793F`；状态配文字，岩点颜色仅表示线路色；设备中文黑体、4 px 间距体系、常用触控目标至少 44×44 逻辑像素。 |
