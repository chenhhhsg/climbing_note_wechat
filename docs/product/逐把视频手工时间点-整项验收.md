## 使用流程

从「单线记录 → 原把次 → 回看视频」或「记录 → 原场次 → 原线路 → 原把次」打开已保存的视频。播放至想记的位置，点「记下当前时间」。列表按时间排序，点某一条跳到对应位置。移除一条时间点后，其余时间点和原视频仍可用。时间点和视频留在同一手机的攀笔中。

## 同一候选的验收

| 项目 | 离线及开发者工具 | 负责人手机 |
| --- | --- | --- |
| V1 · 原把与重开 | 同线两把，仅在 B 的已保存片段记两个不同时间点。复核原档案、原场、原线、原把、片段 ID/版本和持久毫秒值。跨场同线和同名异线不串点。旧索引首次打开为空且只读。 | 在隔离测试线给 B 记点。退出并重开已加载的预览，在断网状态从 B 与原场历史读回同两个点，A 保持原状。 |
| V2 · 实际画面 | 用带可见烧录时间码的 30 FPS 和 60 FPS 样片，分别记下第 5 秒附近的当前时间，再从历史点回。分别记录保存目标、`seek` 参数和烧录画面落点，画面与保存目标差值 ≤0.5 秒。0 秒可记，片尾不越界。元数据未就绪、缺片、未知或非法位置阻止保存并给可辨提示。 | 在手机微信用测试样片点回已记时间。核对目标和实际画面，记录手机系统、微信版本和误差，缺设备的系统单列待验。 |
| V3 · 重试和隔离 | 注入写入前失败、写入完成但回执丢失、索引暂不可读。保留原列表，同一次重试只新增一个点。旧页面或旧片源的迟到事件、连点、切换 A/B 都不能写错对象。删除单点前后比对其他点、原视频、训练结果和备注。 | 从 B 删一个时间点，确认其他点、视频和备注仍可用。 |
| V4 · 片段生命周期 | 选替换片再取消，原列表保留。确认换片后新片为空列表，旧回调不能给新片挂点。移除视频副本和永久删除把次后，原关联的标记被结清。用共享文件及索引故障重开验证剩余关联与副本保留，待清理项结清。普通撤销沿用原规则，随后新记的新 ID 不接管原点。 | 取消换片后原片和时间点仍在。确认换片后，新片从空列表开始。用可删除样片验证移除本机副本后相册原片仍在。只用专门测试把次验证永久删除。 |
| V5 · 数据与包 | 清缓存前后核对在用时间点、视频、训练档案和照片。正式构建含生产依赖，样片和验收材料留在包外。网络记录中时间点操作与回看无视频上传。 | 应用内普通清缓存后，仍在用的标记、视频和照片可回看。 |

批准后交 ZCode 在独立工作区完成自测。独立 QA 在同一冻结候选复跑全量及 V1–V5，记录候选 SHA、实际测试输出、播放器请求与画面证据。负责人用同一候选完成手机复验后另行决定收尾。
