## 用户会看到什么

- 快速新建保留名称、可选照片和独立的颜色属性。左侧选攀岩类型，右侧选难度。抱石使用 V 级，顶绳和先锋使用 YDS。两个类型共有的等级保留，失效值立即清空并显示「请选择等级」。选定有效组合后「创建并选中」才可保存。
- 同一用户在同一条抱石线上可以多次记未完成。点完攀先显示「保存中」。保存失败或回执丢失时可在原把次上重试。确认成功后按钮收起，原位置显示「已完攀」，之后跨场、跨天均可回看照片、尝试和备注。
- 顶绳和先锋完攀后仍可记录。线路按长期 ID 区分，保留试用身份、数据集和照片归属。旧 V 级线路按抱石读取，历史多条完攀原样保留，旧汇总沿用只读展示。

## 同一候选的整体验收

| 场景 | 操作与可观察的结果 |
|---|---|
| A1 首次完攀与线路隔离 | 周四在蓝色动态线记两把未完成，第二把写备注。周日在同一条线完攀并连点，再重开、跨天从历史进入。总计三把、仅一把完攀，第二把的备注和线路照片可回看。今日页、历史项和详情显示「已完攀」，历史项直达详情。该线全部新增入口均关闭，另一条蓝色 V3 仍能记录。 |
| A2 异常恢复与写入去重 | 分别注入落账前保存失败、账本已写但回执丢失。本地未确认期间显示原待确认项与重试入口。开另一页面或场次并尝试新增或直接调用保存入口，再重试原操作。记录操作 ID、待确认数、账本及本地把数，最终同一个原操作确认一次，待确认为零。新操作 ID 也不能给已完攀抱石线加把次。 |
| A3 类型和等级联动 | 抱石选 V3 → 顶绳显示「请选择等级」且不能创建 → 选 5.10a → 先锋仍为 5.10a → 切回抱石清空并要求重选。单独向创建入口传入错配值应无新增线路。颜色和已选可选照片在切换类型时仍属于当前表单。 |
| A4 持久化、旧数据与绳攀 | 分别创建三种线路，切回、重开后在列表与详情核对类型、等级、颜色、备注、照片及稳定 ID。顶绳、先锋完攀后可再记。读入无类型的旧 V 线及历史多次完攀，仍见原始全部记录且禁止新增；旧汇总保持原文，无虚构尝试。 |
