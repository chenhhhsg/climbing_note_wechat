## 同一候选的验收

| 场景 | 操作与通过条件 |
| --- | --- |
| V1 卡片与连续记把 | 用同色同级及长名称线路核对本场、小结和底栏场次卡。进单线连续记未完成与完攀，每一把独立成框，最新在前，编号、结果和配色可辨。编辑、备注和视频均对应原把次。 |
| V2 更正、撤回和恢复 | 连续保存两把，给其中一把保留备注和视频。更正合资格完攀后总把数保持，完攀少一。撤回合资格最新一把后总数减一，原位恢复加一。验证取消、连点、写失败后重试、迟到回执和重开，核对原编号、备注和视频引用。 |
| V3 原场回看 | 同一长期线路在两场都有记录。从底栏进入第一场小结，选线先看到该场逐把，主动点「线路历史」才看到两场。核对同日多馆、同馆多场与跨午夜归原日期。回看零写入，返回仍可继续原活动场和原选中线路。 |
| V4 320/390 小屏与真机 | 两个逻辑宽度分别检查长线路名、长备注、长短列表与软键盘。首屏记把和照片入口可达，照片预览与编辑不遮必用控件，可滚动到最后一把。真机验证同页记把、原把视频回看和照片跨页共享。 |
| V5 文案口径 | 核对四个统计标题与实际数值、个人资料用途及本机保存位置、视频先预览再确认保存本机副本。用同一夹具检查统计、资料入口和视频回看行为。 |

独立 QA 以最终冻结候选核对范围及全量测试，记录通过、失败、跳过和退出码。开发者工具核对 320/390 宽度及可操作的原生路径。手机相机、相册权限、触屏及软键盘由负责人在同一候选复验。返工后在新候选复验受影响项和核心路径。
