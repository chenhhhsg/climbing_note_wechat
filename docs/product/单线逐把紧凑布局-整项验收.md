## 同一候选验收

| 场景 | 通过条件 |
| --- | --- |
| C1 320/390 窄屏与三到四把切换 | 用同一条可连续记把的顶绳或先锋线，准备含完攀／未完成及长备注的三把，在 320、390 逻辑像素宽度测量第 3 把完整卡和前两把短行。约 100 px、48 px 是样稿参考；完整卡明显高于短行，旧行边框、原序号、结果文字、时间和对比度可辨。成功记第 4 把后第 4 把置顶，第 3 把自动收成短行，原编号和内容保持。取消、失败或未落盘的操作保持原卡层级，成功重试才切换一次。 |
| C2 展开与按把编辑 | 点旧行展开被点的原把，核对备注、结果、时间和可用操作。切换展开与编辑时，迟到点击或输入不得落到另一把。收合或浏览零写入。首屏记把和照片入口仍可达，长备注的摘要收成单行，展开后能查看原内容。 |
| C3 本机视频 | 最新把无片时显示「＋ 添加视频」，有片时在同位置显示「回看视频」。旧行收起仅在有片时显示视频图标，展开可给该把添加或回看。把不同视频分别保存到新、旧两把，确认各自文件和索引关联，退出并断网重开仍从对应把播放。取消选片、更换取消及迟到回调保持原片和其他把次，视频页说明保存在这台手机的攀笔中。 |
| C4 纠错、撤回与恢复 | 用符合现有更正资格的抱石线验证。最新一把右侧「更多」仅显示原资格允许的动作，菜单项在两个宽度均可点。更正合资格完攀后有效总把数保持、完攀少一。由原规则允许的最近一把撤回后少一，原行显示「已撤回」与「恢复」，恢复后加一。较早合资格完攀从自己详情更正。验证取消、连点、失败重试及重开，原把次 ID、备注、视频和场次均保持一致。 |
| C5 既有流程回归 | 抱石锁定和绳攀可重复记把遵循现有规则。照片和卡点、底栏原场逐把、跨场线路历史继续按原 ID 打开，单线现场仍能正常返回本场。当前训练、其他线和其他场的数据与试用工程原样保留。 |

独立 QA 绑定最终候选 SHA，核对批准范围、全量测试和原生布局。离线注入保存失败、过期事件与回执，原生记录两宽截图、实测高度和菜单交互。负责人用同候选在微信手机验证视频选片／回看、软键盘、相册权限与点按。返工后用更新后的同一候选复验受影响项和核心流程。
