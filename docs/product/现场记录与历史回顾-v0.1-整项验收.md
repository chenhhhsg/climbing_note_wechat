## 同一候选的五条验收

| 场景 | 操作与通过条件 |
| --- | --- |
| 1 · 照片跨页 | 单线记录给 A 线拍或选一张照片并确认。从线路历史看到同一张缩略图与照片版本，进入已有二级页核对已有标记及位置，返回后数量一致。B 线保留自己的照片和标记。独立 QA 同时核对取消换图及迟到回调不会改到 B 线。 |
| 2 · 本场逐把与跨天历史 | 同线准备两场及一条同名线。本场逐把只列原场原线路，点对应行能读到原备注和播放原把次的本机视频。线路历史继续按原场次展示该线跨日记录。 |
| 3 · 两把纠错闭环 | 同线已有两把，其中一把是符合资格的抱石完攀且带备注和视频。更正后仍是两把，完攀数减一，原把次 ID、序号、备注和视频关联一致。从最近一把撤回后有效把数减一，原位恢复后加一。独立 QA 另测取消、重复点击、写失败后重试、重开及迟到回执。 |
| 4 · 底栏回看 | 用同日两馆、同馆两场及跨午夜的夹具验证日期倒序、按原岩馆 ID 分组及每场一行。跨午夜的把次仍归原场日期。点击场次行及其路线能读到原场小结、原线照片和历史。浏览前后的当前场、当前线路和训练档案保持一致，回首页继续原活动场。旧记录继续按原 ID 打开。 |
| 5 · 现场首屏与真机 | 在同一个集成候选上用两种手机宽度核对单线首屏的记把按钮和紧凑照片入口。独立 QA 核查原生编译、相册/相机路径和导航后，负责人在手机微信按以上路径走一次，记录候选 hash 和通过或卡点。 |

独立 QA 在最终候选复跑全套离线测试，检查基线差异与批准范围，汇总一份验收报告和 verdict。真实拍照、相册权限、手机重开和触屏布局按真机证据登记。返工后在新的同一候选复验受影响项及核心路径。
